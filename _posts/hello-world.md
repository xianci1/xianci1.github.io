你好，欢迎来到我的博客！

这个博客参考了 [Kreal study blog](https://krealhtz.github.io/) 的样式和结构：首页、文章、分类、标签、关于、友链，外加一个站内搜索。

## 本站特点

- **零依赖**：纯 HTML / CSS / JavaScript，不需要安装 Node.js 或 Python
- **免费托管**：可以直接部署到 GitHub Pages
- **自动聚合**：文章列表、分类、标签、搜索都由 `js/data.js` 自动生成

## 如何写一篇文章

1. 在 `_posts` 目录新建一个 Markdown 文件，开头写上标题、日期、分类、标签
2. 正文用 Markdown 写
3. 运行 `.\build.ps1`，首页、文章列表、分类、标签、搜索会自动更新
