文章排版与写作指南

本站文章直接写在 HTML 里，下面的元素都可以直接复制使用。

标题层级

用 <h2> 分大节，<h3> 分小节，<h4> 做更细的分层：

这是一个三级标题

三级标题下的正文。

这是一个四级标题

四级标题下的正文。

列表

无序列表

  • 第一项
  • 第二项
    • 嵌套列表项
  • 第三项

有序列表

  1. 第一步
  2. 第二步
  3. 第三步

表格

项目 说明 示例
行内代码 正文里提到代码时使用 npm install
代码块 多行代码使用 <pre><code>…</code></pre>

引用

这是引用块，适合放名言、原文摘录或重要提示。

代码块

function hello(name) {
  console.log("你好，" + name);
}

hello("世界");

图片

图片放在 assets/ 目录里，用 <img> 引用（注意文章页要加 ../）：

<img src="../assets/favicon.svg" alt="站点图标">

强调与链接

可以用 加粗 和 斜体 突出重点，用 链接 引用外部资料。
